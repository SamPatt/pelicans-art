How it works · Watch the skits

Your agent can write the SVG artwork and dialogue, add local voices, and render a finished video. Open the same project in the Editor whenever you want to make visual changes.

  1. Copy the prompt below into an agent that can read files and run commands, such as Hermes, OpenClaw, or your coding agent.
  2. It downloads the skill, fetches the runtime, and sets up rendering and local speech if needed. The theater makes no additional OpenRouter or other LLM API calls.
  3. Get a test video and an editable project. Then bring your own skit idea—or pick an absurd suggestion from your agent.
Get the skill · v1.0.3

No manual clone or skill installation needed. The skill download is public; the runtime repository is currently private, so your agent still needs existing Git access. A configured read-only deploy key works.

Open Editor → choose Open project and select the generated output/project.json. Recorded dialogue is retained for unchanged lines.

Edit in your browser or keep talking to your agent. The private local Editor can also connect to Hermes for chat. Your agent handles new voices and final video rendering.
