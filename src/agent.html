Manual editing optional

Agent chat is the primary way to create and edit your skits. Keep asking your agent for changes to the artwork, dialogue, voices, or timing; it can return an updated video.

If you prefer to make visual changes yourself, open the Editor, choose Open project, and select the generated output/project.json. Recorded dialogue is retained for unchanged lines.

On your private local or VPS installation, the Editor can also connect to Hermes for chat, update voices, and render a downloadable video.
