Behind the pouch

How it works

pelicans.art turns model-generated SVG into reusable actors, then directs those actors with a small, inspectable action language.

The pelican that started it

The project was inspired by Simon Willison's pelican-on-a-bicycle test. That experiment asked language models to draw one surprisingly difficult SVG scene. This project asks a follow-up: if a model can draw a character, can we give that character a face, a voice, stage directions, and comic timing?

1. Generate SVG
2. Add animation hooks
3. Direct in JSON
4. Perform & capture

A deliberately constrained stage

Characters are ordinary SVG files with stable IDs for parts such as eyes, pupils, and mouths. A skit is a JSON sequence of actions—not generated JavaScript—so dialogue, movement, expressions, camera shots, and props can be inspected and replayed deterministically.

{ "do": "say",   "who": "pelican", "line": "Places, everyone." }
{ "do": "emote", "who": "pelican", "emotion": "nervous" }
{ "do": "shot",   "type": "closeup", "target": "pelican" }

Voices and mouth timing

Published skits bundle their audio alongside the script. During playback, the player measures the active audio clock and drives mouth shapes against that same timeline. The capture tool waits for an explicit audio-start signal, records the browser performance, and normalizes both audio and video to the same zero point before producing H.264/AAC MP4.

Local-first authoring

The browser studio keeps projects and provider settings in local IndexedDB and local storage. Requests go directly to the provider the user selects. A separate Express server supports local publishing, voice processing, and live updates, but it is an authoring tool for a trusted machine or private network—not a public backend.

Untrusted SVG stays untrusted

Community and generated SVG is sanitized before it is inserted into the page. Executable tags, event handlers, CSS imports, and external URL references are stripped; the internal IDs and fragment references required for animation are retained.

The source is being prepared for release under MIT. Creative assets have separate terms. Until the repository is public, the working demo and the captioned pelican bicycle skit are the best ways to explore it. A second original example, The Box, shows a longer character exchange.
