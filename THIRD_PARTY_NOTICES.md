This project includes [DOMPurify](https://github.com/cure53/DOMPurify) 3.4.14 in `src/vendor/dompurify/` to sanitize SVG before inline rendering. DOMPurify is available under the Mozilla Public License 2.0 or Apache License 2.0; its license text is included beside the vendored file.

The site currently loads typefaces from Google Fonts. Visiting the hosted site may therefore make a request to Google's font infrastructure. The retained legacy Studio can store provider keys locally and send requests to the selected provider. The companion Editor has no provider-key configuration; its optional agent and voice connections use the user’s private authoring server. Browser projects are stored locally unless the user exports or publishes them.
