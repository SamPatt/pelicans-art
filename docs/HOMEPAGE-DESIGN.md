# Seaside pocket theater

The homepage should feel like a playful stage operated by birds, while making watching and creating immediately understandable.

Palette: feather white #fffdf5, sea teal #087f8c, wing ink #123940, bill yellow #ffc94a, stage coral #f49889, pale surf #dcefeb. Display type uses a heavy grotesque system stack; body uses a plain system sans. Large left-aligned headlines carry the personality, with quieter functional labels.

Layout: navigation; headline beside an Astra pelican cutout; a prominent video and its program note; an open three-column invitation to watch/create/remix; reusable Pouch assets; the interactive repertory player.

```
logo                         watch / pouch / studio
The birds have the mic.              [Astra pelican]
[ The Description video          ]  program note
watch                 make                 remix
[ community cast and props, manually scrollable ]
[ now playing: The Description                   ]
```

Critique: generic rounded feature cards and decorative waves were the prior site's strongest template signals. Replace the cards with an open layout and put the bold shape around the actual theater. Limit motion to one brief mascot entrance, with reduced-motion support. Existing character art and real skit imagery provide the identity, without adding gratuitous illustrations.

References reviewed: the current Anthropic frontend-design skill (https://github.com/anthropics/skills/tree/main/skills/frontend-design) and web.dev's reduced-motion guidance (https://web.dev/articles/prefers-reduced-motion).
