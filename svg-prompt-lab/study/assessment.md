# How to use this study

Start in the review gallery with methods hidden. For each of the six briefs, choose one or more favorites, switch to thumbnail size, and note the most important defect in otherwise promising drawings. The five optional axes separate fidelity, recognition, appeal, distinctiveness and production usability. Leave an axis unrated if the available evidence is insufficient. Inspect SVG structure and animation before treating usability as established.

Then reveal the methods and compare every candidate with **Current agent guide**, keeping **Current browser recipe** as a separate historical control. The controls use the same study dimensions and technical contract as the other recipes. This is a comparison of harmonized first drafts, not a reproduction of every step an agent or browser would normally perform.

For the repeat/revision comparison, assess two workflows: selecting from the original agent-guide draft plus its visual revision, versus selecting from the same original draft plus a second fresh draft. Record ties; also note any revision that made its parent worse. Both offer two generated candidates, but this is not a token-matched or cost-matched experiment.

Export ratings before changing devices. The gallery stores ratings only on the device and records whether method labels have been revealed. A favorite is a useful preference signal; it is not a calibrated quality measurement. The generating team's visual observations must remain separate from these user judgments.

## What would justify a guide change?

| Possible change | Evidence to look for | Reasons to hesitate |
|---|---|---|
| Add explicit art direction | Better silhouette and character across several briefs, with required details retained | One attractive subject, or improved color hiding a missing prop |
| Add a short layout plan | Clearer object relationships, fewer collisions and unobstructed actor floor | More planning text without visibly better results |
| Supply existing SVG examples | More consistent, editable structures and readable shapes | Copying an unsuitable silhouette or repeated visual style |
| Require a rendered correction pass | Visible improvements over the parent and over a second fresh draft | Added complexity, new defects, or changes unrelated to the brief |
| Relax old human-proportion rules | Better nonhuman anatomy while the required rig still works | An attractive still whose mouth or head animation breaks |
| Simplify prompts | Comparable preferences and compatibility from the shorter recipe | One lucky draft; shared contract already supplies many constraints |

Do not promote a recipe on aggregate aesthetics alone. Check the category: a good prop recipe may be poor at staging backgrounds. The technical results include failures and warnings; do not remove unsuccessful candidates before comparing methods.

## Confirmation before changing the default

Use the best one or two recipes on held-out briefs, retaining the current agent guide control. A practical next round is three new briefs per category, three fresh samples per recipe, and a second independent rater if available. Predeclare which criteria matter most. Run the shortlisted characters through actual talking, gaze, emotion, facing and holding-prop behavior in the player; the gallery's mouth and gaze images are only approximate probes. Test backgrounds behind two actors at mobile size.

Only then update the relevant guide. Keep required runtime structure separate from optional art direction and examples. Record the exact prompt revision and examples so future model upgrades can be assessed against the same baseline.
