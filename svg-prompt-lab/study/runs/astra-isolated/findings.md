# Completed Astra SVG prompting pilot

48 of 48 SVGs generated and rendered; all passed the structural gates. Three candidates have edge-proximity warnings (t011, t015, t044). Two clock drafts have visible unintended geometry despite valid SVG. No human ratings have been collected and no aesthetic winner is declared.

The six briefs each include both current controls, four alternatives, an independent repeat of the agent control, and one visual revision. The exact recipe snapshots, raw outputs, plans, critiques, provenance, previews and technical results are retained. The controls share the study contract; this is not an unconstrained end-to-end agent test.

## Author observations (unblinded)

### The current agent guide is a credible control

My unblinded reading does not support throwing out the current guide. The stagehand control (t043) has a long-necked pelican silhouette, a readable cable and coherent clothing. The browser control (t002) is more compact and human-proportioned. Art direction (t003) is simpler, while the layout draft (t004) conveys fatigue more explicitly. These are choices to judge, not evidence of a universal winning recipe. The independent agent draft (t031) also varies visibly without changing the prompt.

### Mushroom chef: targeted revision fixes a specific overlap

The current-agent draft (t044) places the spoon bowl against the cap rim. Its revision (t038) moves the spoon into clear space and adjusts the brow expression. That separation is visible in the rendered pair. The minimal draft (t006) and layout draft (t009) are also coherent mushroom characters; extra guidance is not a prerequisite for a usable still. The browser draft (t007) has a more human-like torso, making species silhouette a useful criterion when comparing it.

### Clock: valid code can still draw the wrong thing

The minimal (t011) and reference (t015) clocks contain a stray dark shape above the roof. Their doorway paths use uppercase A with endpoints such as 22,0 and 20,0; the resulting absolute arcs differ from the apparent intended relative displacement. Both remain valid SVG and pass structural gates. The current-agent control (t045) avoids this defect. Its revision (t039) separates the bird, clock and slot, but makes the bird smaller—a thumbnail tradeoff to judge. These two defective drafts were not the parents of the revision condition, so this study does not demonstrate that revision repairs that particular error.

### Teapot: style and proportion are separate decisions

The current-agent control (t046) uses a decorative purple-and-gold treatment. Its revision (t040) reduces the crown and ornament and opens more space inside the handle. The layout draft (t019) instead uses an ivory-and-gold treatment; art direction (t018) uses flatter teal shapes. The second current-agent draft (t034) is less ornamented than the first. This amount of variation is a reason to compare independent drafts before attributing a preferred style solely to a recipe.

### Laundromat: inspect staging and local intersections

The current-agent control (t047) is detailed and readable, but the machine divider touches the door rims and the floor begins slightly below the requested quarter-frame boundary. Its revision (t041) separates those lines and raises the clear floor. Art direction (t023) produces larger, flatter blocks of color; the layout draft (t024) is more restrained. All should still be tested behind actual actors: an empty floor in a still does not establish good staging.

### Moon office: spacing corrections can preserve a design

The current-agent control (t048) overlaps the service-hatch frame with the rear window frame. Its revision (t042) moves the hatch boundary away from the window while retaining the scene. The layout draft (t029) is spare; the art-direction draft (t028) has bolder, more angular forms. The browser control (t027) and fresh agent repeat (t036) remain plausible alternatives. Preference and subject fidelity need human comparison; there is no numerical aesthetic ranking here.

### Provisional recommendation

Keep the current agent guide as the baseline while collecting your blind preferences. Preserve its existing render-and-inspect step, and consider making object clearance, intended expression, small-size readability and actor space explicit checklist items. Offer one bounded, targeted correction pass rather than assuming a large new prompt will solve everything. Keep art direction, layout planning and SVG examples as candidate options until held-out tests show when they help. These are proposals only; production prompts have not been changed.

## Limits and next decision

This is a six-brief, one-model screening pilot. A fresh history-free context was used per trial, but file restrictions were instruction-based. Inference settings and token usage were unavailable; the seed randomizes dispatch only. The two-candidate workflows are not token-matched. Human preferences, confidence and rationale remain to be collected through the gallery. No production prompt changes or public asset publication were made.
