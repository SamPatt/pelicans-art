# SVG art direction

Use this visual guidance for new characters, props and backgrounds unless the user supplies a different style. Keep the subject brief and runtime SVG requirements alongside it; art direction does not replace required animation IDs, dimensions or safe SVG structure. When revising existing artwork, preserve its established appearance unless the user asks to restyle it.

> Design this as a characterful theatrical vector illustration. Establish one memorable silhouette and a clear focal feature. Use deliberate asymmetry where it serves the brief, controlled contrast, no more than six main colors, and generous separation between important shapes. Avoid tiny decorative marks that vanish at phone size. Favor a few expressive contours over stacks of generic circles. Preserve every required object and relationship.

Treat the palette and shape guidance as creative defaults, not validation rules. A requested subject or reference style may need a different treatment. Preserve nonhuman anatomy instead of forcing every character into human proportions; keep backgrounds usable as stages with clear space for the actors.

Inspect the rendered PNG at normal and thumbnail size. Check the intended expression, prop silhouettes, object overlaps, stray geometry, clipping and staging space. If a visible defect needs correction, make a focused revision and inspect it again while preserving the previous version. A structurally valid SVG is not proof that the drawing reads correctly.
